MOVEMENT BECOMES LEARNING

화면의 시각 정보를 제공하고
움직임을 유도합니다.

SPOMOVE는 화면의 색·위치·방향·형태·리듬을 4색 패드와 신체활동으로 연결하는 스크린 기반 체육교육 프로그램입니다. 자극의 속도와 규칙을 조절해 참여자의 연령과 발달 수준에 맞는 움직임을 이끌어냅니다.

4색 패드단순·선택·복합 반응연령별 난이도 조절교구 연계 수업
현장에서 가장 먼저 이해되는 구성한 장의 화면과 네 장의 패드가 기준이 됩니다. 아이들은 화면을 보고 각 패드 위치를 선택하며 움직임을 시작합니다.
같은 구성도 대상에 따라 다르게 운영미취학부터 중학생, 특수아동과 느린학습자까지 속도·횟수·시간과 규칙을 조절해 맞춤 수업으로 확장합니다.
01 · FOUR-COLOR PAD

한 장의 4색 패드가
움직임의 기준이 됩니다.

빨강·노랑·초록·파랑의 고정된 공간은 화면의 신호를 실제 발 위치로 연결합니다. 아이는 색을 맞히는 데서 끝나지 않고, 목표 위치를 선택해 이동하고 멈추며 다음 동작을 준비합니다.

화면의 정보가 곧 움직임의 신호가 됩니다.

같은 패드 위에서도 화면에 무엇이, 어디에, 어떤 순서와 속도로 나타나는지에 따라 전혀 다른 신체활동이 만들어집니다.

1. 인지화면의 색·위치·방향·형태 변화를 확인합니다.
2. 선택여러 정보 중 현재 규칙에 필요한 반응을 결정합니다.
3. 수행선택한 반응을 스텝·점프·터치·방향 전환으로 실행합니다.
4. 조절리듬과 순서에 맞춰 움직임의 속도와 타이밍을 이어갑니다.
02 · PROGRAM STRUCTURE

반응의 수준을
네 가지 영역으로 설계합니다.

SPOMOVE는 여러 게임을 단순히 모아 놓은 프로그램이 아닙니다. 하나의 자극에 바로 움직이는 단계부터 규칙·억제·기억이 필요한 과제와 몰입형 움직임까지 체계적으로 확장합니다.

1

단순 반응

하나의 자극을 보고 정해진 위치나 동작으로 즉시 연결합니다.

  • 시지각 반응
  • 반응 인지
2

선택 반응

여러 자극과 방해 정보 속에서 필요한 목표를 골라 움직입니다.

  • 사이먼 효과
  • 플랭커
3

복합 반응

규칙을 유지하고 익숙한 반응을 억제하며 순서를 기억해 수행합니다.

  • 스트룹 과제
  • 순차 기억
4

몰입 프로그램

화면 속 공간 안에서 달리고, 점프하고, 피하며 전신으로 반응합니다.

  • 3D DIVE MODE
  • 몰입형 신체활동
핵심은 ‘빨리’보다 ‘알맞게’입니다. 자극을 정확히 구분하고, 필요한 반응을 선택하며, 발의 위치와 몸의 균형을 조절해 하나의 수행을 완성합니다.

일부러 헷갈리게 만들고,
알맞은 반응을 선택하게 합니다.

선택·복합 반응에서는 색, 위치, 방향, 글자처럼 서로 다른 정보가 일치하거나 충돌하도록 설계합니다. 아이는 눈에 먼저 들어오는 정보에 그대로 반응하지 않고, 현재 규칙에 필요한 정보만 선택해 움직여야 합니다.

SIMON EFFECT

사이먼 효과

자극이 나타난 위치와 정답이 가리키는 위치가 다를 때, 눈에 보이는 위치로 바로 움직이려는 반응을 멈추고 색 규칙에 맞는 패드를 선택합니다.

반응 선택 · 공간정보 분리 · 자동 반응 억제
FLANKER TASK

플랭커

가운데 목표 주변에 같은 색 또는 다른 색의 방해 자극을 함께 제시합니다. 주변 정보에 흔들리지 않고 중심 목표만 찾아 정확하게 움직입니다.

선택적 주의 · 방해 자극 통제 · 반응 정확성
STROOP TASK

스트룹 과제

글자의 의미, 글자색, 화살표 방향처럼 서로 다른 정보가 충돌하도록 제시합니다. 그때 정해진 기준만 선택하고 익숙한 반응을 억제해 수행합니다.

규칙 유지 · 반응 억제 · 규칙 전환
03 · MOVEMENT

인지 과제는 실제
움직임 기술로 완성됩니다.

화면에서 정답을 찾는 것만으로는 끝나지 않습니다. 선택한 반응을 몸으로 정확히 실행해야 SPOMOVE의 과제가 완성됩니다.

MOVE & STOP

이동하고 멈추기

움직인 뒤 정확한 위치에 멈추고, 다음 이동을 준비하며 몸을 조절합니다.

이동 · 정지 · 위치 조절 · 다음 동작 준비
BALANCE & CONTROL

균형과 자세 조절

한 발 스텝, 양발 점프와 방향 전환 과정에서 착지와 무게중심을 조절합니다.

스텝 · 점프 · 방향 전환 · 착지 · 균형 조절
OBJECT CONTROL

다양한 교구

화면 규칙과 공·풍선·컵·콘·후프·원마커·스카프·타격 도구를 연결해 손과 발의 움직임으로 확장합니다.

굴리기 · 던지기 · 옮기기 · 쌓기 · 치기 · 터치
같은 화면 신호도 수업 목표에 따라 패드 밟기 → 점프와 방향 전환 → 공 옮기기 → 후프 이동 → 타겟 치기 → 교구 미션으로 달라집니다. 화면은 반응의 기준을 제시하고, 체육교구는 그 반응을 실제 움직임 기술로 확장합니다.
04 · VISUAL REACTION THEMES

같은 4색도
제시 방식이 바뀌면 다른 게임이 됩니다.

시지각 반응 안에서도 자극의 흐름, 등장 시간, 위치, 배열, 속도를 바꿔 다양한 콘텐츠를 구성합니다. 리듬게임처럼 반복하고 몰입하지만, 매 순간 몸으로 반응해야 합니다.

리듬·흐름형플로우, 펄스, 러시처럼 일정한 박자와 흐름에 맞춰 연속 반응합니다.
순간 탐지형플래시, 블랙아웃처럼 짧게 나타나는 목표를 빠르게 발견합니다.
공간·패턴형패턴, 대각선, 스윕처럼 위치와 방향의 변화를 읽고 이동합니다.
게임·몰입형심해 반응과 몰 두더지처럼 화면 연출과 타겟 탐색을 결합합니다.
아이와 수업에 맞게 조절합니다.

자극 속도, 훈련 시간, 등장 간격, 유아용 안전 모드 등을 조절해 같은 콘텐츠도 난이도를 다르게 운영할 수 있습니다.

05 · CONTENT EXPANSION

훈련에서 놀이로,
패드에서 교구로 확장됩니다.

기본 반응 구조는 그대로 유지하면서 화면 표현과 움직임 과제를 바꿉니다. 그래서 한 번 익힌 규칙을 여러 형태의 신체활동으로 반복하고 확장할 수 있습니다.

🎵

리듬 챌린지

색과 박자에 맞춰 스텝·점프·터치를 이어가며 움직임의 시작과 정지 타이밍을 경험합니다.

🎯

타겟 반응 놀이

화면에서 목표 색과 위치를 찾아 이동한 뒤 두더지잡기, 타겟 터치, 정확히 치기와 같은 게임으로 연결합니다.

🧩

교구 결합 미션

색 신호에 따라 공을 굴리거나 던지고, 컵·콘을 옮기고, 후프를 통과하며 밴드·로프·타격 도구까지 다양하게 활용합니다.

🐸

연상 움직임

동물·탈것·자연물에서 떠오르는 색과 동작을 연결해 이야기가 있는 움직임 활동으로 확장합니다.

정확한 선택현재 규칙에 맞는 색·위치·동작을 고르는가
안정적인 움직임이동·정지·착지·교구 조작을 조절하는가
적절한 난이도속도·규칙·이동 범위를 참여자에게 맞추는가
