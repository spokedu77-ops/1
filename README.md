# SPOKEDU web/app

Next.js application for the public SPOKEDU website, instructor LAB (internal code name MASTER), Admin operations, and SPOMOVE.

- Agent entry and authorization: [AGENTS.md](AGENTS.md)
- Current product/domain documentation: [docs/README.md](docs/README.md)
- Test and local QA selection: [docs/TESTING.md](docs/TESTING.md)
- Operational scripts: [scripts/README.md](scripts/README.md)

Local development uses `npm run dev:local` from this repository root. It checks local configuration and serves http://127.0.0.1:3000. Do not print credentials or commit `.env.local`.

Use the user's current approved scope. Old reports, screenshots, completed briefs and test counts are historical evidence, not current instructions or permission to publish. Git and deployment authorization is defined in AGENTS.md.
