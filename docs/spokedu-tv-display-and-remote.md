# SPOKEDU — TV 디스플레이 · 리모컨 사용 지침

## Phase 0 (현재 권장 · 현장 표준)

TV는 **디스플레이만**, 조작은 **노트북/태블릿**에서 한다.

1. 노트북(또는 태블릿)에서 MASTER / SPOMOVE / admin 실행
2. HDMI(또는 미러링)로 TV에 출력
3. 시작·일시정지·종료·설정은 노트북 마우스/터치로 조작
4. 프로젝터·전체화면 모드는 기존 제품 계약 그대로 사용

TV 브라우저에 주소를 직접 열고 **리모컨만으로** UI를 조작하는 방식은 현재 지원 대상이 아니다.

### 현장 피드백 대응 요약

| 증상 | 의미 | 대응 |
| --- | --- | --- |
| 파란 박스가 안 움직임 | TV 브라우저 포커스(리모컨 내비게이션) — 페이지에 포커스 UX 없음 | HDMI + 노트북 조작 |
| 배율 100이 최대 | TV/브라우저 줌 상한 | 플레이어·전체화면으로 화면을 키움 (브라우저 줌에 의존하지 않음) |
| 기타 조작 불가 | 리모컨 ≠ 마우스 | Phase 0 사용법 유지 |

## Phase 1 (별도 요청 시 · SPOMOVE 프로젝터만)

admin 전체 UI가 아니라 **실행/프로젝터 화면**에 한정.

- 방향키 + Enter/Back으로 시작·일시정지·종료·난이도만
- 큰 focus ring, 스크롤 대신 고정 컨트롤 바
- 배율은 브라우저 줌이 아니라 플레이어 내부 scale

## Phase 2 (비권장)

제조사별 TV 브라우저(Tizen/webOS 등) 네이티브 대응 — 유지비 대비 우선순위 낮음.
