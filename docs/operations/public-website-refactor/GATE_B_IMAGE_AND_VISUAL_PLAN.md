# SPOKEDU 홈페이지 Gate B — 이미지 선별 및 비주얼 구성안

작성일: 2026-10-20
범위: 공개 홈페이지 `/`, `/education`, `/spomove`, `/records`, `/partners` 및 연관 공개 페이지
상태: **사진 후보 선별 완료 / 공개 권한 확인 및 디자인 PO 승인 대기**

## 조사 결론

- 현재 홈 Hero의 `home-hero-gym-motion.jpg`는 실제 수업 사진이 아니라 연출·생성형 이미지로 보인다. Gate B의 “실제 교육 현장” 기준에 맞지 않아 **교체**한다.
- 저장소에는 실제 현장 사진이 이미 다수 있으며, 특히 SPOMOVE·맞춤형 체육·기관 행사·PAPS·강사교육은 서비스 가치를 직접 설명한다.
- Google Drive에는 기관수업, 개인수업 선별본, SPOMOVE 원본·최종본, 서대문 진로부스 원본이 확인된다. 그러나 Drive 소유권이나 `shared=false`는 촬영·홈페이지 공개 동의를 의미하지 않는다.
- Drive에서 `초상권 협업 클래스`, `꿈꾸는땅지역아동센터(초상권동의)`, `스포키듀 초상권 동의 관련 신청서 발췌 건.pdf`가 확인되었지만, 개별 후보 사진과 동의 범위를 연결하는 증거는 확인되지 않았다. 따라서 얼굴 식별 가능한 아동 사진은 모두 **RIGHTS_PENDING**으로 둔다.
- 이번 Gate B에서는 파일을 복사하거나 홈페이지 이미지를 교체하지 않았다.

### 이미지 내 텍스트 배치

- Hero는 사진 위 직접 문구를 최소화하고, 현재처럼 별도 copy rail을 우선한다. 실제 수업 사진은 정보량이 많아 오버레이 텍스트 가독성이 불안정하다.
- H-02는 좌측 인물·우측 화면 구조가 있어 텍스트 오버레이보다 인접 2열 구성이 안전하다.
- H-03은 정사각형에 가까워 모바일 카드에 적합하지만 데스크톱 와이드 Hero에는 확대하지 않는다.
- H-05/D-03은 브랜드 표기가 사진 안에 있으므로 과도한 자막을 겹치지 않는다.

## C. 홈페이지 개선 방향 — Gate C 준비안

### 첫 화면 핵심 메시지

고객이 첫 화면에서 이해해야 할 것은 “무엇을 파는가”보다 다음 세 가지다.

1. SPOKEDU는 실제 교육 현장에서 수업을 운영한다.
2. 학교·기관·개인 맞춤 수업과 SPOMOVE를 목적에 맞게 설계한다.
3. 수업 실행뿐 아니라 콘텐츠와 운영 도구까지 연결한다.

Hero는 실제 현장 사진 + 한 문장 가치 제안 + 고객 유형 선택으로 구성한다. 생성형 체육관 이미지는 제거한다.

### 고객별 진입 경로

| 고객 | 첫 질문 | 권장 진입 | 최종 CTA |
|---|---|---|---|
| 학교·기관 담당자 | 우리 대상과 공간에 맞는 수업을 운영할 수 있는가 | 실제 기관 사례 → 프로그램 방식 → 운영 범위 | 기관 수업 상담 |

### 설득력 부족 지점과 개선 원칙

- **현 Hero의 진정성 부족:** 연출/생성형 이미지가 실제 서비스 증거처럼 보인다. 실제 SPOMOVE·기관수업 사진으로 교체한다.
- **같은 사진의 과다 재사용:** 한 장을 Hero·서비스·사례에서 반복하면 사례 폭이 좁아 보인다. 페이지별 역할이 다른 원본을 배정한다.
- **기능 화면과 현장 사진의 관계 부족:** LAB UI만 보여주지 말고 “준비 → 실제 수업 → 기록” 순서로 연결한다. 다만 기능 의미나 CTA 목적지는 Gate C 승인 전 변경하지 않는다.
- **고객 유형 진입이 늦음:** Hero 직후 학교·기관 / 학부모 / 지도자 / 협력의 네 경로를 명확히 한다.
- **사례의 증거 밀도 부족:** 사진마다 기관 유형, 대상, 프로그램, 수업 목적을 사실 확인된 짧은 캡션으로 붙인다. 성과 수치는 근거가 있을 때만 사용한다.
- **CTA 혼재:** 각 경로에는 하나의 다음 행동만 둔다. 상담, LAB 확인, 제품/구독은 동일한 버튼 문법을 쓰되 목적지는 구분한다.
- **브랜드 유지:** SPOMOVE, SPOMAT, SPOKEDU LAB 표기는 현재 제품 계약대로 유지한다.

## 승인 필요 항목
