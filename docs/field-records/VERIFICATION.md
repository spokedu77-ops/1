화면·브라우저 결과: `.tmp/field-records-qa/results.json` 및 같은 폴더의 PNG. 본문 렌더는 실제 React 컴포넌트와 로컬 CSS를 사용했다. 관리자 저장 요청만 브라우저 내부 fixture에 연결했으며, 실제 인증·DB·Storage 통합 E2E를 통과한 것으로 취급하지 않는다.

마이그레이션은 적용했으며, 콘텐츠 등록·게시 승인 후 다음을 실제 환경에서 확인해야 한다.

- 관리자 인증 세션으로 초안 등록·편집·게시·취소
- 실제 비공개 Storage 업로드·변경·삭제와 공개 접근 철회
- 운영 메타데이터·canonical·OG·사이트맵과 캐시 갱신
- 실자료의 사진 동의 확인 및 기존 관리자 동작 최종 확인

후속 확인: 사용자가 관리자에서 세 원고를 등록·게시했다. 공개본 3건을 읽기 확인한 뒤, 기존 홈 순서대로 매동 1 / 동작 2 / 동행 3번을 연결하고 로컬 CMS 전환 플래그를 활성화했다. 실제 로컬 홈의 내부 상세 링크 3개와 `/records`, 세 상세 경로의 HTTP 200 응답을 확인했다. 운영 배포·운영 환경변수 변경은 실행하지 않았다. 사진 업로드·삭제의 실제 Storage 통합 검증은 위 fixture/단위 검증과 별도로 남아 있다.
