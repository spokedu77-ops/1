## 운영 적용과 로컬 코드 구분

이번 검사에서 운영에 적용한 것은 다음 함수 마이그레이션이다. 수업 배정·단가·상태·시간을 영구 변경하는 복구 UPDATE/DELETE는 추가 실행하지 않았다.

- `20261031202334_classops_status_transition_slots`: 비활성 상태 전환의 예약 해제.
- `20261031202455_classops_restore_slot_conflict_guard`: 복구 전환이 보조 제거 최적화를 타지 않도록 하여 전체 충돌 검증·예약 재생성을 수행.
- `20261031204127_classops_atomic_tail_shrink`: 기존 축소 UI 동작을 한 트랜잭션으로 제공. public/anon/authenticated 실행 권한 제거, service_role만 실행 가능.

최종 상태 함수는 `20261031202455`가 소유한다. 신규 cron, 테이블/RLS/정책, 단가 변경은 없다. 보안 Advisor는 검사 전후 신규 항목 0이며 새 RPC의 anon/authenticated 실행 불가를 실제 DB에서 확인했다.

앱·API·UI 개선은 로컬 작업 트리에만 있다. 운영 앱 배포와 Git stage/commit/push는 하지 않았다. 따라서 운영 앱이 새 축소 경로·저장 검증을 사용한다고 주장하지 않는다.

## 검증 근거

- 대상 회귀: 29개 파일 **167개 통과**. 수업 영역과 관련 API·정산만 실행했으며 전체 빌드/전체 테스트는 실행하지 않았다.
- 독립 PostgreSQL: **34개 통과**. 두 연결의 CAS/연기/축소 경쟁, 중복 요청, 마지막 단계 충돌, 마일리지 일부 처리 후 주입 실패, RLS 무변경, 부여 권한, 과거 완료 INSERT 및 DELETE를 포함한다. 실패 전후 sessions·session_count_logs·mileage_logs·users.points·예약 테이블을 비교했다.
- 운영 DB: 상태 변경 재현은 오류로 전체 롤백. 수정 후 취소·연기·충돌 복구 거절·정상 복구·보조 제거·회차 재생성을 롤백 트랜잭션으로 검증했다. 새 축소 함수도 실제 FK/회차/예약 정리까지 실행한 뒤 삭제를 롤백하여 원래 finished·회차 3건을 재확인했다.
- 로컬 실제 관리자 DOM: **1440/390/375px 통과**. 저장/실패/새로고침, 완료와 미처리 구분, 자동 완료 후 상세 재조회, 새 원자 축소의 거절과 성공까지 확인했다. 화면 테스트 요청은 격리 fixture로 가로채 운영 쓰기를 차단했다.
- TypeScript, 변경 파일 lint, diff 공백 검사 통과. 독립 테스트 DB는 제거하고 임시 로컬 서버를 종료했다.
- UI→실제 로그인 세션→실제 운영 API→운영 DB를 하나로 묶은 쓰기 E2E는 실행하지 않았다. 화면·API 계약·독립 DB·운영 롤백 검증을 구분하며, 이를 전체 운영 E2E PASS라고 표현하지 않는다.
