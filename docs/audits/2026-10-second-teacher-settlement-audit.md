3. 운영 Postgres 로그 2026-10-31 20:57:29.873 KST 및 10/31 02:35:30.918 KST에서 동일 오류와 sessions.status 일괄 UPDATE(id = ANY)의 실패가 확인됐다. 조사 중 실행한 읽기 전용 재현과 구별되는 기존 운영 오류다.

## 후속 수정 범위 (미실행)

- 자동 완료에서 DB 조회·변경 오류를 반드시 응답·기록하고 실패를 성공으로 보고하지 않도록 수정.
- 개별 데이터 오류가 다른 수업 전체를 막지 않도록 처리 단위를 분리하고 실제 변경 건수·실패 ID를 검증 가능하게 제공.
- 대치 운동회 실제 보조 배정·수업료 확인 후 잘못된 빈 ID 보정. 완료 상태를 단순 일괄 변경하면 출석·회차·마일리지 트리거 영향이 있으므로 실제 진행 확인 후 처리.
- 정산 당시 지급 대상과 현재 계정 활성 여부를 분리하여 과거 정산 명단 누락 방지. 현재 계정 활성화로 우회하지 않음.
- 정산 화면에 기간 내 미완료 유급 수업·비활성 강사 지급액 및 상단/명단 합계 불일치가 드러나도록 검토.
- 완료 후 세션 지급액, 개인별 목록 합계, 기타 정산, 회차 로그를 재대조. 지급 완료 여부는 현재 저장 데이터로 확인하지 못했으므로 별도 지급 증빙 대조 필요.

이번 요청은 원인 파악과 전수조사로 수행했으며 코드 수정·운영 데이터 보정·테스트 실행·Git 커밋은 하지 않았다. 기존 Sidebar.tsx 변경은 이번 조사와 별도다.
