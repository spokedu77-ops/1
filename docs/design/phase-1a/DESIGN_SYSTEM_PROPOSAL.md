# SPOKEDU Unified Design System V1 — Phase 1-A 제안서

> 상태: 승인 전 디자인 제안 · DESIGN_ONLY  
> 범위: 공개 홈페이지와 공개 서비스 랜딩의 공통 시각 언어  
> 제외: Production 적용, 라우팅·기능·정책 변경, LAB 로그인 후 대시보드

## 1. 디자인 원칙

1. **세 고객의 다음 행동을 먼저 보인다.** 기관·학교 담당자, 학부모, 지도자가 첫 화면에서 자신의 경로를 구분할 수 있어야 한다.
2. **하나의 브랜드, 서로 다른 역할을 유지한다.** 공통 색상·타입·버튼·간격·헤더는 통일하되 기관수업, 개인수업, SPOMOVE, SPOMAT, LAB의 콘텐츠 구성은 각 목적에 맞춘다.
3. **현장 증거가 장식보다 우선한다.** 실제 수업 사진과 실제 제품 화면만 증거로 사용하며 합성 이미지나 출처가 불명확한 이미지를 실사처럼 제시하지 않는다.
4. **정보 구조가 카드 수를 결정한다.** 서비스 선택은 Service Card, 실제 사례는 Evidence Card, 조건·절차는 Information Card 또는 목록으로 표현한다.
5. **주요 행동은 한눈에 하나다.** 한 화면의 핵심 CTA는 Primary로, 보조 행동은 Secondary 또는 Text Link로 구분한다.
6. **모바일은 읽는 순서를 다시 설계한다.** 데스크톱 열을 축소하지 않고 메시지 → 증거 → 행동 순서로 재배치한다.

## 2. 토큰

### 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| Brand Primary | `#245DFF` | 공개 사이트 Primary CTA, 선택, 포커스 |
| Brand Navy | `#0B1F46` | 주요 제목, 브랜드 다크 영역 |
| Text Primary | `#14213A` | 기본 텍스트 |
| Text Secondary | `#536279` | 설명과 부가 정보 |
| Surface White | `#FFFFFF` | 기본 배경 |
| Surface Soft | `#F5F7FB` | 보조 섹션 |
| Border | `#DCE3EE` | 카드·입력·구분선 |
| Accent Orange | `#FC5606` | 기관수업의 라벨·선·작은 강조에 제한 |

- 개인수업의 틸은 작은 분류 라벨이나 상태 표현에만 허용하고 CTA에는 사용하지 않는다.
- SPOMOVE·SPOMAT의 빨강·노랑·초록·파랑은 기능 색상으로 보존한다.
- 새 브랜드 색이나 장식용 그라데이션은 추가하지 않는다.
- 다크 배경 본문은 흰색 계열을 사용하고 작은 본문에 오렌지·블루 조합을 사용하지 않는다.

### 타이포그래피

기본 서체는 기존 공개 사이트 설정과 동일한 `Pretendard` 계열이다. 새 폰트 파일이나 외부 다운로드는 사용하지 않는다.

| 역할 | 데스크톱 | 모바일 | 굵기 | 줄간격 |
|---|---:|---:|---:|---:|
| Home Display 예외 | 92px 시안 (`72~108px` 검토 범위) | 48px | 800 | 0.94~1.0 |
| 일반 페이지 H1 | 64px | 36px | 700 | 1.1 |
| 섹션 H2 | 44px | 28px | 700 | 1.15 |
| 카드 H3 | 22px | 18px | 700 | 1.3 |
| 주요 본문 | 17px | 16px | 400 | 1.6 |
| 보조 본문 | 15px | 14px | 400~500 | 1.6 |
| Eyebrow / Label | 12px | 12px | 600~700 | 1.3 |

- 한글은 `word-break: keep-all`과 자연스러운 줄바꿈을 사용한다.
- 홈의 `MOVEMENT BECOMES LEARNING.`은 브랜드 Display 예외로 유지하되 한글 핵심 메시지보다 의미상 우선하지 않는다. 이번 split hero 시안은 단어 중간 줄바꿈을 피하기 위해 92px을 사용하며, 기존 108px은 더 넓은 전폭 구성에서 유지 가능한 선택지로 남긴다.
- 긴 설명에는 14px 미만 글자를 사용하지 않는다.

### 버튼

| 유형 | 규칙 | 상태 |
|---|---|---|
| Primary | 파랑 배경, 흰 글자, 50px(모바일 최소 48px), 반경 10px, 15px/600 | Hover `#174BE6`, Focus 3px 연한 파랑 외곽선, Disabled 45% 불투명도 |
| Secondary | 흰색 또는 투명 배경, Border, Navy 글자, Primary와 같은 크기 | Hover Soft 배경, Focus 동일, Disabled 45% 불투명도 |
| Text Link | 44px 이상 터치 영역, 화살표 또는 밑줄 | Hover 밑줄, Focus 외곽선, Disabled 미사용 |

고객에게 같은 중요도의 행동은 같은 유형으로 표현한다. 기관수업의 오렌지는 공통 Primary 버튼을 대체하지 않는다.

### 레이아웃과 간격

- 콘텐츠 최대 너비: 1280px
- 좌우 여백: 데스크톱 48px, 태블릿 32px, 모바일 20px
- 간격 스케일: 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px
- 카드 기본 반경: 16px
- 헤더 높이: 데스크톱 76px, 모바일 64px
- 그림자: 메뉴·모달·부유 레이어에만 제한적으로 사용
- 텍스트와 카드 콘텐츠는 1280px 축을 공유하고, 현장 사진은 목적이 명확할 때만 더 넓게 확장한다.

### 카드

| 유형 | 필수 요소 | 시각 규칙 |
|---|---|---|
| Service Card | 고객 유형, 서비스명, 한 줄 설명, 이동 행동 | 이미지 선택 사항, 16px 반경, 얕은 테두리, 행동을 하단에 고정 |
| Evidence Card | 실제 현장 사진, 기관·프로그램명, 대상/운영 방식, 사례 링크 | 사진 필수, 16:10 또는 4:3, 과도한 오버레이 금지 |
| Information Card | 조건·기능·절차의 짧은 설명 | 장식과 그림자 최소화, 내용이 길면 카드 대신 목록 |

## 3. 공통 헤더와 모바일 메뉴

- 현재 메뉴 SSOT의 이름과 목적지를 유지한다: `체육수업`, `솔루션`, `현장 사례`, `소개`, `상담하기`.
- 데스크톱은 왼쪽 워드마크, 중앙 내비게이션, 오른쪽 Primary CTA 구조를 사용한다.
- 로고는 투명 워드마크를 사용하고 시각 높이는 데스크톱 약 40px, 모바일 약 32px로 제한한다.
- 활성 메뉴는 파랑 밑줄과 Navy 글자로 표시한다. 색상만으로 상태를 전달하지 않는다.
- 헤더는 흰색 sticky 표면과 하단 Border를 사용한다. 스크롤 시 크기 변화나 과한 그림자는 도입하지 않는다.
- 모바일 메뉴 버튼과 닫기 버튼은 최소 44×44px이다. 메뉴는 헤더 아래 전체 너비 패널로 열리고 `체육수업`과 `솔루션`을 그룹으로 구분한다.
- 열림 시 배경 스크롤을 잠그고 첫 메뉴로 포커스를 이동한다. `Esc`로 닫은 뒤 메뉴 버튼으로 포커스를 복귀하며 패널 내부에 포커스를 가둔다.
- LAB 로그인 후 대시보드와 SaaS 로컬 내비게이션은 이 공통 헤더의 적용 대상이 아니다.

## 4. 현재 디자인과 제안의 차이

| 영역 | 현재 확인 | V1 제안 | 고객 관점의 이유 |
|---|---|---|---|
| Home | Navy/Blue, 최대 108px 영문 Display, 에디토리얼 12열 | 108px 특징은 보존하고 한글 약속을 먼저 이해하도록 위계 조정 | 영문 브랜드 감도와 즉시 이해를 함께 확보 |
| 기관수업 | 검정·오렌지, 72px H1, pill CTA, 1280px 독립 그리드 | 오렌지는 섹션 표식으로 보존, Primary CTA는 파랑·10px 반경 | 페이지 개성은 유지하면서 행동 의미를 통일 |
| 개인수업 | 틸 라벨·배지와 다수 카드 | 틸은 분류 보조색으로 축소, CTA·타입·반경은 공통 규칙 | 학부모가 행동 우선순위를 쉽게 구분 |
| SPOMOVE | 다크 미디어 Hero, 텍스트형 CTA, 별도 밀도 | 다크/기능 4색과 미디어 중심 구성 보존, 공통 CTA 문법만 적용 | 제품 정체성을 잃지 않고 브랜드 연결 강화 |
| SPOMAT | 공통 마케팅 유틸과 제품 설명형 구성 | 제품 4색은 보존, 공통 H1·버튼·간격 적용 | 하드웨어 설명의 명료성과 브랜드 일관성 확보 |
| SPOKEDU LAB 공개 랜딩 | 독립 로컬 헤더, 74px급 H1, 1120~1220px 축, 제품 UI 중심 | 공개 브랜드 진입은 공통 규칙과 연결하되 대시보드는 분리 | 지도자용 제품의 전문성을 유지하면서 브랜드 단절 완화 |

## 5. 공통 규칙과 의도적 예외

- **Home Display:** 기존 최대 108px 영문 표현을 유일한 Display 예외로 보존한다.
- **기관 오렌지:** Eyebrow, 얇은 선, 사례 번호처럼 제한된 강조에만 사용한다. Primary CTA에는 사용하지 않는다.
- **개인 틸:** 학부모 맥락의 분류 보조색으로만 사용하고 두 번째 Primary처럼 보이지 않게 한다.
- **SPOMOVE·SPOMAT:** 기능적 4색과 다크 제품 장면은 그대로 유지한다.
- **LAB:** 공개 랜딩과 로그인 후 작업 UI는 목적이 다르므로 동일한 헤더·구성을 강제하지 않는다.
- **실제 사진:** 이번 시안 Hero는 내부 문서에서 실제 위례초 현장으로 확인된 `home-hero-field.webp`를 사용한다. 합성으로 표시된 홈 Hero/Service 자산은 제외했다.

## 6. 근거와 제한

- 확인한 현재 근거: `SPOKEDU_PUBLIC_AUDIT.md`, 실제 라우팅과 컴포넌트, `app/globals.css` 공개 마케팅 토큰, Home/기관/개인/SPOMOVE/SPOMAT/LAB 공개 랜딩 코드.
- `SPOKEDU_DESIGN_UX_AUDIT.md`와 `design-audit-captures/`는 저장소에서 찾지 못해 근거로 사용하지 않았다.
- 기존 Production 화면 캡처를 새로 수집하거나 운영 서비스를 테스트하지 않았다. 이번 렌더 검증은 독립 HTML 시안에만 수행한다.
- 이 문서는 구현 명세가 아니라 승인 전 제안이다. Production 적용은 별도 Phase 1-B 승인 범위가 필요하다.
