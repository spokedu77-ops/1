# Expert UX Audit — SPOMOVE & LAB (Home)

**방법:** 휴리스틱·콘텐츠·제품 기능 대조·Playwright(현재 홈)·전문가 과업 점검 (실사용자 테스트 아님)

## SPOMOVE — 현재 문제

1. **작동 원리:** 한 장의 현장 사진만으로 “화면 신호 → 움직임” 연결이 약함. 화면 UI가 작거나 잘려 보일 수 있음.
2. **용어:** `색상 인지 · 선택 반응 · 복합 인지`는 공개 SPOMOVE `content.levels`와 방향은 맞으나, 홈만으로는 **단순/선택/복합**과 SEE·DECIDE·MOVE 관계가 즉시 연결되지 않음.
3. **ADAPT:** 공개 랜딩에는 `variation`(ADAPT) 존재. 홈 3단만으로는 조절·난이도 메시지 없음 — **누락이 아니라 요약 수준** (ADAPT 추가는 별도 Product Decision).
4. **중복:** Method·Records에서 SPOMOVE/현장 이미지와 메시지가 일부 겹침 — 본 섹션은 **프로그램 사용법·반응형 활동**에 초점 필요.
5. **CTA:** `/spomove` 랜딩은 flow·experience 제공 — **양호**. catalog 경로는 별도 품질 이슈 가능(16-1).

## LAB — 현재 문제

1. **기능 과장 위험:** “출석·기록까지”가 **Free 사용자**에게도 전체 제공처럼 읽힐 수 있음 (Lite+ 실제).
2. **`144+`:** 수치 근거 미연결 — 신뢰 리스크.
3. **UI 이미지:** 데스크톱 art-directed crop은 라이브러리 탐색은 보여주나, **운영·기록**은 copy에만 의존.
4. **모바일:** `.productFrame img` 230% 확대·좌측 고정 — 필터·카드 일부는 보이나 **전체 제품 구조 오인** 가능 (SOURCE §9).
5. **대상:** “지도자용”이 eyebrow/lead에 명시적이지 않음 — 기관 담당자가 LAB을 기관 수업 대행과 혼동할 여지는 Gateway/Method로 일부 완화됨.

## 고객별 이해도 (현재 홈)

| 고객 | SPOMOVE | LAB |
|---|---|---|
| 기관 담당자 | 현장 사진으로 운영 가능성은 보임 | 콘텐츠·운영 도구 구분 약함 |
| 학부모 | 영상 vs 활동 구분 불충분 | 해당 낮음 |
| 지도자 | 프로그램명·3단은 보임 | 기능 나열은 있으나 권한 경계 불명 |
| 신규 LAB | — | CTA·랜딩 경로는 있음, 무료 범위는 홈에서 불명 |

## 제품 간 차별성

- **SPOMOVE:** 활동·반응 (MOVE 중심) — **양호하나 시각 증거 부족**
- **LAB:** 준비·운영 SaaS — **UI는 있으나 가치·권한 설명 부족**
- 두 섹션 모두 split/product 패턴으로 **시각적 차별**은 있음

## 정보구조·모바일·브랜드
