## 시나리오 10개 (실행하지 않은 쓰기 포함)

| # | 명령 | 가능한 단계 | 하지 않은 이유 |
|---|---|---|---|
| 1 | 이번 달 수업 현황 | 날짜 계산 도구 + 일별 세션 조회까지가 설계 한계. 월 집계 없음 | 인증 쓰기 없이 조회만 가능하나 오늘 호출 안 함. 집계는 미구현 |
| 2 | 센터 정산 개발 진행 | 저장소 대화·깃 로그를 보는 도구 없음 | 이 채팅의 감사와 무관하게 비서는 진행도를 저장하지 않음 |
| 3 | 기관별 미정산 | 도구 없음 | |
| 4 | 이번 주 강사별 수업 | 세션 API가 강사 주간 뷰를 반환하는지는 호출 전이라 미확인. Calendar는 강사 축이 아님 | 읽기 호출은 다음 단계에서 승인된 읽기 검증으로 가능 |
| 5 | 수업 자료로 계획서 | RAG가 살아 있으면 발췌 후 모델이 초안 작성. 지금 임베딩이 꺼져 검색 단계가 막힘 | 초안 생성은 외부 쓰기가 아님. 검색부터 실패 가능 |
| 6 | 지난 블로그 원고 | `reports\naver_new\...\ARTICLE_FOR_REVIEW.md` 등 파일이 디스크에 있음. MCP 검색 도구로 연결되지 않음 | |
| 7 | 반복 피드백 문제 | 피드백 교정 품질 코드는 제품 앱에 있음. “반복 오류 분석” 잡 없음. 1,088건 코퍼스 미확인 | |
| 8 | 승인된 변경을 DB에 반영 | Supabase 쓰기 도구 없음. 지침이 원본 수정 금지를 명시 | 실행하지 않음 |
| 9 | 실행 결과·변경 데이터 | 실패 로그만 있음 | 보여줄 성공 감사 로그가 없음 |
| 10 | 실패 작업 원인과 재실행 | 로그에 원인 문자열은 있음(빈 인자, OAuth, 날짜 형식). 재실행 큐 없음 | 재실행은 쓰기·외부 호출이라 보류 |

READY로 올릴 항목은 없다. 모델 프로세스 생존만 확인했고, 업무 시나리오를 끝까지 태우지 않았기 때문이다.
