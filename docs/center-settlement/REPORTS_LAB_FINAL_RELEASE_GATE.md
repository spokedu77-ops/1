**장애·복구:** 브라우저 요청 중단, 조회 API 500, 비정상 JSON은 오류 안내 후 재조회로 복구했다. 비정상 응답 구조는 기존 전역 오류 화면에서 새로고침해 복구했다. 각 장애 후 기존 정산 접근과 원본 해시 보존을 확인했다. 세션 만료 상황은 인증 쿠키 제거로 모의했다.

**격리 경로:** LAB 저장은 네트워크 없는 `labTransport`에만 도달한다. 공유 연결·강사 단가 컴포넌트는 GET 조회만 사용하며, LAB 하위 경로에서 센터 CRUD Server Action을 호출하지 않는다. 실제 MASTER로 LAB 서버의 PUT·POST·PATCH·DELETE를 직접 요청해도 모두 **405 / Allow: GET**이었다. 서버 외부 요청도 기록하고 운영 쓰기·RPC 차단 장치를 적용했으며, 정상 검증에서 차단 장치가 개입한 쓰기 시도는 없었다.

검증은 **로컬 Production 서버 + 실제 운영 데이터 읽기**로 수행했다. 인증 우회·계정 생성·권한 변경·비밀번호 변경은 하지 않았다. 제품 소스의 검증 전후 해시가 동일하며 추가 기능·리팩토링도 없다. 임시 서버·검증 브라우저를 종료하고 새로 캡처한 세션 파일은 삭제했다.

증빙은 로컬 `.tmp/reports-lab-final/`의 `tests.json`, `typecheck.log`, `build.log`, `live-e2e.json`, `failure-e2e.json`, `write-boundary.json`, `server-network.jsonl`, `final-summary.json`에 기록했다. 비밀번호·토큰은 보고서에 포함하지 않았다.

**운영 DB 수정·실제 매핑 저장·commit·push·deploy 미실행.** 배포는 별도 지시 후 진행한다. 페이지 전환이나 코드 롤백이 기존 운영 화면에서 발생한 실제 DB 변경을 자동 복구하는 것은 아니다.
